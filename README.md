# הספריה שלי

אתר לניהול ספריה ביתית: רשימת ספרים, קטגוריות, והשאלות - כולל שרת MCP לפתיחה ולסגירה של השאלות.

## הפעלה על המחשב

נדרש Node.js בגרסה 20 ומעלה.

```bash
npm install
```

```bash
npm start
```

האתר נפתח בכתובת <http://localhost:3000>. בלי הגדרות נוספות הנתונים נשמרים במסד מקומי בתיקייה `data/`, והאתר נגיש רק מהמחשב הזה, בלי סיסמה.

## העלאה לענן: Supabase + Render

המסד יושב ב-Supabase, והאתר וה-MCP רצים כשירות אחד ב-Render. שניהם בתוכנית החינמית.

1. **Supabase** - יוצרים פרויקט חדש ושומרים את סיסמת המסד. בכפתור Connect מעתיקים את כתובת החיבור מסוג **Session pooler** ומחליפים בה את `[YOUR-PASSWORD]` בסיסמה. הטבלאות נוצרות לבד בהפעלה הראשונה.
2. **Render** - New → Blueprint, בוחרים את המאגר הזה. Render קורא את `render.yaml` ומבקש שני ערכים:
   - `DATABASE_URL` - הכתובת משלב 1
   - `APP_PASSWORD` - הסיסמה שתשמש לכניסה לאתר
3. אחרי שהפריסה מסתיימת האתר זמין בכתובת ש-Render נותן (`https://....onrender.com`).

כדאי לדעת על התוכניות החינמיות: השירות ב-Render נרדם אחרי כרבע שעה בלי שימוש, והכניסה הראשונה אחר כך אורכת עד כדקה. פרויקט ב-Supabase מושהה אחרי כשבוע בלי פעילות, ומפעילים אותו מחדש מלוח הבקרה.

### משתני סביבה

| משתנה | משמעות |
|---|---|
| `DATABASE_URL` | כתובת החיבור ל-Postgres. בלי המשתנה - מסד מקומי בתיקייה `data/` |
| `APP_PASSWORD` | סיסמת הכניסה לאתר. חובה בענן; בלי המשתנה האתר פתוח (מקומי בלבד) |
| `MCP_TOKEN` | הטוקן של ה-MCP. ב-Render נוצר אוטומטית |
| `PORT`, `HOST` | ברירת מחדל מקומית: `3000`, `127.0.0.1` |

## מה יש באתר

- רשימת ספרים עם שם, סופר, קטגוריה, גיל מומלץ והערות
- חיפוש לפי שם ספר או שם סופר (מתעלם מניקוד ומגרשיים)
- סינון לפי קטגוריה, סופר, גיל מומלץ, ומצב (על המדף / מושאלים)
- השאלה בלחיצה: שם המשאילה ותאריך; החזרה בלחיצה; היסטוריית השאלות לכל ספר
- ניהול קטגוריות: הוספה, שינוי שם ומחיקה
- כניסה בסיסמה (כשמוגדר `APP_PASSWORD`)
- הוספה מרוכזת: ספר בכל שורה, `שם הספר | סופר | קטגוריה | גיל מומלץ` (אפשר להדביק מאקסל)

## MCP

**בענן (HTTP)** - הכתובת היא `https://<כתובת-האתר>/mcp/<MCP_TOKEN>`. את הטוקן מוצאים ב-Render, בלשונית Environment של השירות. הכתובת הזו היא כמו סיסמה - לא לשתף אותה.

- ב-claude.ai: Settings → Connectors → Add custom connector, ומדביקים את הכתובת.
- ב-Claude Code:

```bash
claude mcp add --transport http library https://<כתובת-האתר>/mcp/<MCP_TOKEN>
```

אפשר גם לשלוח את הטוקן בכותרת `Authorization: Bearer` אל `/mcp`.

**על המחשב (stdio)** - `npm run mcp`. מתחבר לאותו מסד לפי `DATABASE_URL`. בלי `DATABASE_URL` הוא משתמש במסד המקומי, שרק תהליך אחד יכול לפתוח בכל רגע - כלומר לא במקביל לאתר.

### הכלים

| כלי | מה הוא עושה |
|---|---|
| `open_loan` | פתיחת השאלה: `book_title`, `borrower_name` (ואופציונלית `author`, `loan_date`) |
| `close_loan` | סגירת השאלה: `book_title`, `borrower_name` (ואופציונלית `return_date`) |
| `list_open_loans` | מי מחזיקה מה וממתי |
| `search_books` | חיפוש וסינון ברשימת הספרים |
| `add_book` | הוספת ספר |
| `list_categories` | רשימת הקטגוריות |

אפשר לכתוב רק חלק משם הספר. אם השם מתאים לכמה ספרים, הכלי מחזיר את הרשימה ואינו מנחש.
